## 🏗️ System Architecture

```
Raw FBRef CSV (Big 5 Leagues)
        │
        ▼
src/preprocess.py          ← Partner 1
  • Clean, filter (GK / <900 min)
  • Resolve mid-season transfers
  • Compute 14 per-90 metrics
  • Percentile ranks within position
        │
        ▼
src/clustering.py          ← Partner 1
  • StandardScaler + KMeans (k validated by Elbow + Silhouette)
  • Map centroids → football archetypes
  • Generate 2D PCA coordinates
        │
        ▼
data/players_processed.parquet   ← shared data contract
        │
   ┌────┴────────────────────────┐
   ▼                             ▼
src/similarity.py          app/visuals.py
  • Cosine Similarity matrix       • Plotly Cluster Map     ← Partner 1
  • 0-100 % match index            • Radar / Pizza chart
  • Query engine + filters
        │
        ▼
app/main.py                ← Partner 2
  • Streamlit multi-panel dashboard
  • @st.cache_data / @st.cache_resource
  • Sidebar filters: age cap, league, position lock, cluster lock
  • Similarity scorecards + H2H metric table
        │
        ▼
Streamlit Community Cloud  ← Partner 2
  tests/ (pytest CI)       ← Partner 2
```

## 🚀 Quickstart

```bash
# 1. Clone
git clone https://github.com/<YOUR_ORG>/football-scout-ai.git
cd football-scout-ai

# 2. Install (Python 3.11+)
pip install -r requirements.txt

# 3. Generate processed data (Partner 1 must run this first)
python src/preprocess.py
python src/clustering.py

# 4. Launch the app
streamlit run app/main.py
```

## 🧪 Running Tests

```bash
pytest tests/ -v --cov=src --cov-report=term-missing
```

Tests use **synthetic data** (`tests/conftest.py`) — no real dataset required.

| Test class | What it verifies |
|---|---|
| `TestMatrixProperties` | Matrix symmetry, values in [0,100], diagonal = 100 |
| `TestQueryCorrectness` | Self excluded, results sorted, top_n respected, schema |
| `TestFilters` | Age cap, league, position lock, same-cluster, exclude team |
| `TestEdgeCases` | Unknown player raises, empty filter, player search |
| `TestSchemaValidation` | Missing columns raise `ValueError` |
| `TestInternalMath` | `_normalise_to_match_index`, `_scale_metrics` correctness |
